개인정보처리방침 / Privacy Policy

시행일 / Effective Date: 2026-11-25 · 대상 앱 / Apps: Personal Sync (NasSync, TailClip)

1. 수집 및 접근하는 Google 사용자 데이터

  • 기본 계정 식별 정보 (openid, email, profile): 본인 기기 간 동일 Google 계정을 확인하고 화면에 로그인된 이메일을 표시하기 위해서만 사용합니다.
  • Google Drive 앱 전용 폴더 (https://www.googleapis.com/auth/drive.appdata): 앱 자체의 암호화된 설정 스냅샷과 기기 연결 데이터만 읽고 씁니다. 사용자의 일반 Google Drive 파일이나 폴더 목록에는 일절 접근하지 않습니다.

2. 데이터 저장 · 암호화 및 제3자 미제공

  • 클라우드에 저장되는 동기화 데이터는 업로드 전에 사용자 기기에서 클라이언트 측 AES-256-GCM(E2EE)으로 암호화됩니다.
  • OAuth 토큰과 암호키는 기기의 OS 보안 저장소(Windows DPAPI, Android Keystore / Play Block Store)에만 보관합니다.
  • 개발자 운영 서버나 제3자에게 사용자 데이터를 전송·공유·판매·광고 활용하지 않습니다.

3. 데이터 보관 및 삭제

  • 사용자는 앱 내 [로그아웃]으로 기기에 저장된 OAuth 토큰을 즉시 삭제할 수 있습니다.
  • Google 계정 설정(보안 → 서드파티 앱 액세스)에서 Personal Sync의 권한을 철회하거나 Google Drive 앱 데이터 관리에서 앱 전용 저장 데이터를 영구 삭제할 수 있습니다.

English Summary & Google API Limited Use Disclosure

Personal Sync (NasSync and TailClip) uses Google OAuth 2.0 solely to authenticate the user (openid, email, profile) and store client-side AES-256-GCM encrypted configuration backups inside the user's own hidden Google Drive application data folder (https://www.googleapis.com/auth/drive.appdata).

The applications do not access general Google Drive files, do not run remote backend servers that inspect user data, and never sell, share, or use Google user data for advertising or AI/ML model training. Personal Sync's use and transfer of information received from Google APIs strictly adheres to the Google API Services User Data Policy, including the Limited Use requirements.

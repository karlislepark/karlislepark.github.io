Personal Sync (NasSync & TailClip)

Personal Sync는 개인 소유의 Windows PC와 Android 기기 간 설정 백업과 클립보드·파일 동기화를 위한 개인용 유틸리티 앱 묶음(NasSync, TailClip)입니다.

Personal Sync is a suite of personal desktop and mobile utilities (NasSync and TailClip) for backing up configuration snapshots and syncing data strictly between the user's own devices.

핵심 보안 원칙 / Security Principles

  • Google Drive의 앱 전용 숨김 폴더(drive.appdata)만 사용하며, 일반 드라이브 파일에는 접근하지 않습니다.
  • 모든 동기화 데이터는 기기에서 256-bit AES-GCM 종단간 암호화(E2EE) 후 업로드됩니다.
  • 외부 중계 서버나 제3자 분석 도구를 사용하지 않으며, 데이터를 외부로 판매하거나 공유하지 않습니다.
